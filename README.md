# Segundo Cerebro

Tu operación completa, escrita una sola vez, para no volver a explicarla nunca.

Contestas seis preguntas y quedas con tu propio sistema: tus páginas, tu calendario, tu
gente, y herramientas hechas a la medida de lo que tú haces cada semana.

Funciona igual si entrenas un equipo, si tienes una panadería o si llevas clientes tú solo.
Son las mismas seis preguntas — lo que cambia es lo que construye.

---

## Instalación

No tienes que descargar nada a mano. Se lo pides a Claude y él lo hace.

### 1. Instala Claude Code

Descárgalo en **[claude.ai/download](https://claude.ai/download)** e inicia sesión.

Es de pago. Mejor saberlo ahora que a los quince minutos.

### 2. Crea una carpeta vacía y ábrela con Claude Code

Donde quieras y con el nombre que quieras — *mi-sistema*, *mi-negocio*, tu nombre. Ahí va a
vivir todo.

### 3. Pega esto y dale enter:

```
Descarga https://github.com/ne0bopio/segundo-cerebro en esta carpeta
—con git o con el zip, lo que te funcione— y sigue las instrucciones
del CLAUDE.md que viene adentro.
```

Eso es todo. Te va a hacer seis preguntas y construye el resto.

---

## Ve tu sistema como un mapa

La carpeta `wiki/` ya viene preparada como bóveda de Obsidian, con tema oscuro y un mapa a
color.

1. Descarga **[Obsidian](https://obsidian.md)** (gratis)
2. Abre → **Abrir carpeta como bóveda** → elige la carpeta `wiki`
3. **Ajustes → Apariencia → Fragmentos CSS** → activa **quantum-graph**
4. Haz clic en el ícono de **vista de grafo** (los puntos conectados, barra izquierda)

Los colores no vienen puestos de fábrica: se eligen cuando se crean tus carpetas. Ese mapa
es tuyo.

## Después de instalarlo

| Si quieres... | Dile |
|---|---|
| Que actualice algo | "se movió el partido del sábado a las 10" |
| Meter un archivo viejo | tíralo en `wiki/raw/` y di "procesa esto" |
| Guardar un PDF o una imagen | tíralo en `wiki/assets/` y di "catalógalo" |
| Ver en qué andas | "¿cómo voy esta semana?" |

Entre más lo usas, menos te repites.

---

## Preguntas comunes

**¿Mis datos se van a algún lado?**
No. Todo son archivos de texto en tu computadora. Si borras la carpeta, no queda nada.

**¿Me lo puedo llevar a otra computadora?**
Sí. Copia la carpeta y ya. Ahí va todo.

**¿Y si me equivoco contestando?**
Dile qué estuvo mal y lo corrige. Nada de esto es permanente.

**¿Necesito saber programar?**
No. Si sabes usar carpetas, sabes usar esto.
